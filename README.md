# Mado 公開デモ

好きなチャンネルの動画だけを、自分に合う画面で楽しむデモアプリ。

公開 URL: https://cardmaster0.github.io/publicY/

## 使い方

1. カタログで「追加する」を押してチャンネルを選びます。
2. マイライブラリで検索・期間・長さ・並び順を試せます。
3. 表示設定で配色・文字サイズ・表示密度・Shorts 非表示を変更できます。
4. 再生を試す場合は「YouTube 公開サンプル」を選び、詳細で「公式プレーヤーを読み込む」を押します。

選択と設定は各自のブラウザに保存されます。他の利用者とは共有されず、別端末への同期もありません。サイトの保存データを削除するとリセットされます。

5 チャンネル・15 動画は架空の固定デモで、再生素材はありません。公式公開サンプルのみ YouTube の埋め込みを試せます。再生の可否は YouTube と通信環境に依存します。
YouTube Data API は未接続で、任意のチャンネル URL からの取得・追加はできません。カタログ日付・長さは検証用の固定値です。

このリポジトリには公開用の HTML・CSS・JavaScript・自作 SVG のみを配置しています。Node.js サーバー・SQLite・API キーは使いません。
GitHub Pages の配信元は main ブランチのルートです。
